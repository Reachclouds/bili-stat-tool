# B站UP主7天播放量统计工具

Bilibili UP主视频播放量批量统计桌面工具。自动采集UP主在指定时间范围内发布的视频播放数据，区分"已结算"与"统计中"状态，支持历史数据持久化、视频筛选/排除、奖池结算分配、Excel导出。

---

## 环境要求

- Python 3.12+
- 依赖库：`PyQt5`、`openpyxl`、`bilibili-api`

```bash
pip install PyQt5 openpyxl bilibili-api
```

## 启动

```bash
python main.py
```

## 功能说明

### 1. UP主管理

| 操作 | 说明 |
|------|------|
| 单个添加 | 输入UP主的纯数字 UID 和昵称，点击"添加" |
| 批量导入 | 在文本框中按行输入 `UID,昵称`，点击"批量添加" |
| 启用/禁用 | 在左侧列表中勾选/取消勾选UP主（双击也可切换），禁用后统计和导出均跳过 |
| 删除 | 右键点击UP主条目，选择删除 |
| 清空 | 点击"清空列表"一键移除所有UP主 |

- 最多支持 **80** 个UP主
- UP主列表自动保存至 `~/.BiliStatTool/up_list.json`，下次启动自动加载

### 2. 播放量统计

1. 设置**开始日期**和**结束日期**（默认为最近7天）
2. 点击"开始统计"，程序自动遍历所有已启用的UP主
3. 统计过程中可点击"停止统计"中断
4. 统计完成后，表格显示所有视频的7天播放量详情

**视频状态说明：**

| 状态 | 含义 |
|------|------|
| 已结算 | 视频发布已满7天，播放量数据锁定，不再更新 |
| 统计中 | 视频发布未满7天，次日统计时播放量会自动更新 |

**统计结果表格包含：**

| 列 | 说明 |
|----|------|
| UP主昵称 | 视频作者 |
| 视频标题 | 视频名称 |
| BV号 | 视频唯一标识 |
| 发布时间 | 视频发布时间 |
| 7天播放量 | 当前播放次数 |
| 统计天数 | 已统计的天数 |
| 状态 | 已结算 / 统计中 |
| 共创角色 | 若为共创视频，显示该UP主的角色（如"UP主"、"协力"等） |

### 3. 视频筛选与排除

点击"筛选作品"按钮打开筛选对话框：

- **按UP主筛选**：下拉选择特定UP主，仅查看/操作该UP主的视频
- **排除视频**：取消勾选不需要的视频，确认后永久排除（历史数据中也会排除）
- **恢复已排除视频**：勾选"显示已排除的视频"可恢复之前排除的视频
- **批量操作**："全选/全不选"按钮快速切换当前视图的所有视频
- **共创角色筛选**：勾选"排除指定共创角色"可按角色批量排除视频（如排除所有"协力"角色的视频）
- 排除状态持久化存储，跨会话生效

### 4. 奖池结算

点击"奖池结算"按钮打开结算对话框，根据UP主播放量自动分配奖金。

#### 4.1 档位配置

在"档位配置"标签页中管理结算档位：

| 字段 | 说明 |
|------|------|
| 档位名称 | 自定义名称，如"第一档"、"保底档" |
| 累计播放量（门槛） | UP主需达到的最低播放量 |
| 瓜分金额（元） | 该档位的总奖池金额 |
| 单人最高瓜分（元） | 单个UP主在该档位可获得的最高金额 |

- 支持添加、删除、上下移动档位
- 提供默认7档配置，可恢复默认
- 档位按门槛降序排列，UP主自动归属到最高达标档位

#### 4.2 结算规则

采用4步算法逐档分配：

1. **比例分配**：按UP主播放量占该档位总播放量的比例，从奖池中分配
2. **封顶限制**：单人分配金额不超过该档位的"单人最高瓜分"上限
3. **溢出处理**：被封顶截断的金额计入溢出，不重新分配
4. 剩余奖池金额 = 奖池总额 - 已分配总额 - 溢出总额

#### 4.3 数据筛选

- **日期范围**：独立设置视频发布时间筛选，可只结算指定时段发布的视频
- **包含统计中视频**：勾选后可包含未满7天的视频参与结算
- 已排除的视频自动跳过

#### 4.4 预览与应用

- **保存配置**：保存当前档位设置到本地
- **预览结算**：在"结算预览"标签页查看档位汇总和UP主明细（预估收益、实际收益、是否封顶）
- **应用结算**：确认后保存结算结果，可在Excel导出中包含结算数据

### 5. Excel导出

点击"导出Excel"按钮，生成包含三个Sheet的 `.xlsx` 文件：

**Sheet 1 — 视频明细（全部历史）**

| 列 | 说明 |
|----|------|
| UP主昵称 | 视频作者 |
| 视频标题 | 视频名称 |
| BV号 | 视频标识 |
| 发布时间 | 发布时间 |
| 7天播放量 | 播放次数（千分位格式） |
| 统计天数 | 统计天数 |
| 统计状态 | 已结算 / 统计中 |
| 共创角色 | 共创角色 |

- 合并了历史已结算数据 + 本次统计中数据
- 不同UP主自动用不同底色区分
- 自动过滤已排除的视频，仅导出已启用UP主的数据

**Sheet 2 — UP主整体排名**

| 列 | 说明 |
|----|------|
| 档位 | TOP1 / TOP2-3 / TOP4-5 等12级分档 |
| 排名 | 排名序号 |
| UP主昵称 | UP主名称 |
| UID | UP主UID |
| 7天总播放量（整体） | 该UP主所有视频播放量合计 |
| 视频数量 | 参与统计的视频数 |

- 排名按总播放量降序，按档位用不同颜色区分

**Sheet 3 — 奖池结算**（仅在已应用结算后出现）

每个档位为一个独立区块，格式如下：

```
              [第一档]
累计播放量      瓜分奖池      单人最高瓜分
100,000        10,000.00     5,000.00
已达到的作者    每位作者的播放量  作者瓜分金额
作者A          120,000       5,000.00
作者B          110,000       3,500.00

              [第二档]
累计播放量      瓜分奖池      单人最高瓜分
50,000         8,000.00      3,000.00
已达到的作者    每位作者的播放量  作者瓜分金额
...
```

- 表格居中排列，从G列开始
- 每个档位用不同底色区分
- 播放量千分位格式，金额保留两位小数
- 档位之间空一行分隔

### 6. Cookie设置

点击"Cookie设置"按钮，配置B站登录凭证：

| 字段 | 说明 |
|------|------|
| DedeUserID | B站用户ID |
| ac_time_value | 时间戳校验值（默认1000） |
| SESSDATA | 会话数据 |
| bili_jct | CSRF Token |
| buvid3 | 设备标识 |

- Cookie保存至 `~/.BiliStatTool/cookie.json`
- Cookie不完整时自动降级为游客模式

**获取方式：** 浏览器登录B站 → F12 → Application → Cookies → 找到上述字段的值。

### 7. 防风控机制

程序内置多层B站API风控防护：

- **随机延时**：请求间插入随机等待，模拟真人操作节奏
- **UP主顺序随机化**：每次统计随机打乱UP主遍历顺序
- **Referer伪装**：请求头模拟浏览器访问对应UP主空间
- **浏览器指纹伪装**：伪装Chrome 131浏览器
- **HTTP/2**：默认启用HTTP/2协议
- **412风控降级**：触发风控后自动冷却（5-10分钟），然后切换为游客模式重试
- **共创信息获取**：单独请求时附加额外延时（5-15秒）

## 数据存储

所有数据存储在用户目录下：

```
~/.BiliStatTool/
├── up_list.json            # UP主列表配置
├── cookie.json             # Cookie配置
├── settings.json           # 筛选设置（共创角色排除等）
├── video_7day_data.json    # 视频播放量历史数据
├── settlement_config.json  # 奖池结算档位配置
├── settlement_result.json  # 最近一次结算结果
├── backups/                # 自动备份（保留30天）
│   └── video_7day_data_YYYYMMDD.json
└── logs/                   # 崩溃日志
    └── crash_*.txt
```

**数据持久化规则：**

- `video_7day_data.json` 以BV号为key，跨会话累积
- 已结算视频的数据永不更新，播放量锁定
- 统计中视频每次统计时自动更新播放量
- 排除状态持久化，不会因重新统计而丢失
- 每次统计完成后自动创建带时间戳的备份文件
- 超过30天的旧备份自动清理

## 典型使用流程

1. 点击「Cookie设置」，填写B站Cookie
2. 添加UP主：单个输入UID+昵称，或批量导入（格式：`UID,昵称`，每行一个）
3. 设置统计日期范围（默认最近7天）
4. 点击「开始统计」，等待完成
5. （可选）点击「筛选作品」排除不需要的视频
6. （可选）点击「奖池结算」配置档位并结算
7. 点击「导出Excel」保存结果

## 常见问题

**Q: 为什么有些视频播放量一直显示"统计中"？**
A: 视频发布未满7天，播放量还在增长中。满7天后自动变为"已结算"并锁定数据。

**Q: 游客模式和登录模式有什么区别？**
A: 登录模式使用你的Cookie请求API，更稳定；游客模式无需Cookie但更容易触发风控。Cookie不完整时自动降级。

**Q: 导出的Excel包含哪些数据？**
A: 包含三个Sheet：视频明细（全部历史）、UP主整体排名、奖池结算（需先应用结算）。已排除的视频和已禁用的UP主不会出现在导出结果中。

**Q: 如何恢复被排除的视频？**
A: 点击"筛选作品"，勾选"显示已排除的视频"，重新勾选需要恢复的视频后确认即可。

**Q: 统计过程中可以中断吗？**
A: 可以，点击"停止统计"即可。已获取的数据会正常保存。

**Q: 奖池结算的"封顶"是什么意思？**
A: 如果UP主按比例应得金额超过了该档位的"单人最高瓜分"上限，则实际只能获得上限金额，超出部分计入溢出。

**Q: 结算结果可以修改吗？**
A: 结算结果保存在本地，重新打开"奖池结算"调整配置后再次"应用结算"即可覆盖。
